# VM 对照与工程验证 | 2026-10-29

以 `e17060c` 为基线，对当前脚本 VM 运行八轮交替 Node/Wasm 内核对照。两侧使用相同 C++ 输入、O3、LTO、Wasm 异常处理和校验值，解析位于计时区间外。测量期间本任务串行运行性能对照。

| 内核 | 基线中位数 | 当前中位数 | 成本下降 |
| --- | ---: | ---: | ---: |
| 算术 | 28.995 ms | 11.743 ms | 59.5% |
| 函数调用 | 35.998 ms | 16.508 ms | 54.1% |
| 嵌套数组 | 25.172 ms | 15.391 ms | 38.9% |
| 字符串转换 | 46.485 ms | 35.422 ms | 23.8% |

四组内核分别度量运算调度、参数传递、数组与内置函数、字符串转换及其循环开销。[全部样本与源码身份](vm-results.json)包含 Node、编译器、Wasm 哈希和逐轮数据。手机呈现的独立设备结果见[顶点上传对照](../performance-20261007/README.md)。

工程验证使用[统一开发入口](../../docs/DEVELOPMENT.md)，覆盖两种标准异常模式、逐 tick 验证构建、VM 与平台回归、生产 GLSL、固定游戏状态及截图。结果与对应产物身份收录在[验证数据](checks.json)中。
