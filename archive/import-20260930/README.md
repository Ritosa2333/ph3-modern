## 接入验证

浏览器执行器沿原工程编译 55 个翻译单元，包含原脚本管理、对象、敌弹、判定、关卡和 Replay。初始验证覆盖从标题进入第一关、键盘操作及原始 Replay 的第一二关结束帧与分数。

数值字符串格式按平台 ABI 选择：Web 的 `script_real` 使用 binary64，相应格式化参数与实际类型一致。该修正确保游戏脚本取得原值，第一关在 14,485 帧、32,756,990 分结束，第二关在 15,090 帧、147,368,070 分结束。

当前平台结构见[架构](../../docs/ARCHITECTURE.md)，按场景的覆盖范围见[适配表](../../ADAPTATION.md)。
